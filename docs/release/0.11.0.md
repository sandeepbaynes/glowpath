# Glowpath 0.11.0+30

A playable web preview with fold-aware native layouts and clearer wormhole feedback. The public release includes the Cloudflare web package, its file inventory and checksums. [Deployment instructions](cloudflare/README.md).

## What changed

- Half-open displays separate the mission map/countdown from gameplay. Horizontal folds put the board below the fold; vertical folds use side-by-side panes. Outer and fully expanded screens retain the responsive layout.
- Active UIKit reserved regions provide iOS fold geometry; Android uses Flutter display features. Layout responds to geometry, ignores stale frames during rotation, and keeps controls clear of camera/status occlusions as well as normal safe areas.
- Wormhole pipes terminate at the entrance and emerge from the paired exit. A one-shot light transfer shows where a new connection continues. Disconnecting cancels the transfer and extinguishes the exit. Reduced motion uses steady illumination.
- Cloudflare packaging uses fresh staging, content-hashed scripts, local fonts and CanvasKit, upload-limit checks and a SHA-256 inventory.

## Verification

The final integrated suite passes **784 Flutter tests**, with clean static analysis. All **29 foldable tests** pass, including measured camera/status exclusions, 5×5 boards, three game modes and enlarged text. Nine Python packaging tests pass.

Tiles and controls remain at least 48 logical points in the tested fold layouts, with no hinge/camera overlap. Tests also check that puzzle identity, rotations, move count, undo history, countdown and saved state survive posture changes.

Simulator review covered the outer display, expanded display, book and tabletop postures. Browser smoke testing covered first-flight instructions, route editing, free hints, timeout/Retry, returning to Voyage and restoring an edit after reload. The final native occlusion correction was verified by measured-geometry regression tests; physical-device performance and accessibility review remain ongoing.

One regression came directly from simulator measurements: the rotated system status region extended beyond ordinary safe-area padding and overlapped Settings. Each interactive fold pane now retains the largest rectangle outside those active occlusions.

## Preview scope

The public web build disables live ads, purchases, mock transactions and shared leaderboard connections. Saves, cargo, achievements and scores remain local to each browser and origin. Moving domains does not transfer saved progress. No backend account is required.

Game Center, production advertising, purchases and cross-device sync are separate integration work. Native store distribution requires developer-owned signing and store configuration. The public repository contains no signing credentials or provisioning profiles.
