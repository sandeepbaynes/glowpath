# Glowpath 0.11.2+32

Partially open inner displays now use two distinct panes throughout the app. The hinge is a reserved gap, not a place for buttons or reading. The outer display keeps its single-screen layout.

- **Gameplay:** the map and launch instruments occupy the top/left pane; the puzzle stays below/right. On short clamshells, tools live with the instruments so the puzzle retains useful tile sizes. Fully opening keeps the board in the same pane.
- **Voyage:** the explorable planetary map occupies one half, with destination, progress, Play and navigation in the other.
- **Briefings and flight:** artwork and flight animations occupy one half, with instructions and actions in the other. Failure shows its flight scene opposite the Retry action. Challenge results separate the score artwork from the recap and next actions.
- **Panels:** Flight notes, controls, collection, supplies, league and route log occupy one half beside a paused voyage view. Panels already open respond to folding; local tabs and carousel state survive reparenting. Restart confirmation and license reading also stay inside a pane.
- **Short panes:** settings paginate pace choices and retain 48-point controls. Help and long briefing copy paginate instead of clipping. Reduced motion remains supported.

## Free access

Paid offers and restore-purchase controls have been removed. A legacy purchase build flag cannot activate checkout in the app. Hints, skips and powers still use currency earned through play; there is no cash purchase. The remaining supply shortcut now says “Free flight support.” Ads and live services remain off in the preview. Watch editions are planned, not implemented.

## Verification

**876 Flutter tests pass**, with clean static analysis. Manual iPhone simulator review covered tabletop and book layouts, opening settings while folded, and preserving the selected section through rotation and half-open ↔ fully-open changes.

The shared resolver uses actual native divisions or Android fold/hinge features, rejects stale geometry during rotation, and excludes safe areas and camera cutouts. Flat gameplay retains inactive native anchors; ordinary flat phone/tablet layouts retain their existing presentation.

Regression tests cover book, tabletop and compact flip layouts; whole-app navigation; already-open panels changing posture; and enlarged text up to 3× in short panels. The compact gameplay instrument scale remains capped as described in [0.11.1](0.11.1.md), with full semantic countdown labels.

Reproduce the new whole-app captures with:

```sh
flutter test test/fold_app_surfaces_test.dart --dart-define=CAPTURE_FOLD_SURFACES=true
```

Images are written to `build/review/fold-surfaces/`. These combine actual app widgets with deterministic test preferences; no real player's save is changed. Android fold geometry is synthetic; physical Samsung/Motorola review remains outstanding.

The Cloudflare package is `glowpath-0.11.2-32-cloudflare-preview-root.zip`. Upload it using the [Cloudflare handoff guide](cloudflare/README.md). This release does not deploy account services or publish native store builds.
