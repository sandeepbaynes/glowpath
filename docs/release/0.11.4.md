# Glowpath 0.11.4

Horizontal countdowns now use the fold display's launch treatment. The rocket advances along a ticked flight rail, leaves a trail, and builds exhaust as launch approaches. The remaining-time readout stays anchored. Phone, tablet, desktop and compact horizontal layouts share this treatment; the vertical fold timer keeps its existing direction.

The countdown mechanics, pause behavior, haptics and failure transition are unchanged. App and system reduced-motion settings suppress travel animation while keeping time and thrust status visible.

Validation: **905 Flutter tests pass**, with clean static analysis. Phone, tablet and desktop renders were visually inspected at early and late countdown states; timer strips also cover expiration. The horizontal rail's easing settles between clock updates so normal gameplay and accessibility views remain stable.

The [ad and analytics plan](AD_AND_ANALYTICS_PLAN.md) describes proposed placements and measurements. A local pacing rule and bounded on-device event journal are wired to game transitions. They cannot show ads or upload events. Production ad units, consent, hosted measurement and player-facing placement review remain separate release work.

Cloudflare tooling is installed locally in `tools/cloudflare`. Its commands explicitly select a named `glowpath` authentication profile with per-command keychain storage; they do not replace a machine's global Wrangler default. Live ads and purchases remain disabled in the web preview.
