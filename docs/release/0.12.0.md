# Glowpath 0.12.0

Version `0.12.0+35` publishes the public web game at [glowpath-38p.pages.dev](https://glowpath-38p.pages.dev/) and adds native mobile advertising integration. Web deployment is verified; native owner-device review is tracked separately below.

## Public website

The public web package includes privacy and support pages, publisher ownership metadata for `ca-pub-3704137344359613`, and an indexable site configuration. Fonts and renderer assets remain self-hosted. The game stores progress by browser and origin, so saves do not transfer automatically to another browser, website address or mobile device.

The Google account's active advertising product is currently AdMob. AdSense enrollment could not complete Google's human-verification step, so site review has not been successfully submitted and eligibility of the Pages address remains unverified. AdSense Content and H5 Games approval and browser integration remain pending. The public website loads no advertising provider script and sends no ad requests. Its build metadata records `publisherConfigured: true`, `servingStatus: pending_approval_and_integration` and `liveAds: false`; publisher ownership configuration does not mean ad serving is approved.

Cloudflare commands explicitly select the keychain-backed `sandeepbaynes` profile. The profile has no directory binding and does not replace the Mac's default Wrangler account. The same profile may be reused by other projects in the account. See the [deployment guide](cloudflare/README.md).

## Native advertising

The iOS and Android apps have real AdMob app IDs and separate banner, level-break interstitial, three-hint and one-skip rewarded units. Native ad requests are gated by the build configuration and the provider's consent decision. Owner-device review uses registered test devices; test advertising does not establish revenue or production fill.

Default local builds keep ads disabled. Native review builds enable ads explicitly and use review mode. If no test-device IDs are registered in a review build, the adapter falls back to Google's demo ad units. Live store distribution remains separate from local review and requires store linkage, AdMob review and completed placement/consent testing. See the [ad and measurement plan](AD_AND_ANALYTICS_PLAN.md).

## Privacy and verification status

There is no player account, cross-device identity or hosted gameplay analytics endpoint. Progress and the bounded game event journal are stored locally. Native advertising, when enabled, is handled by Google Mobile Ads after the consent gate; the public privacy notice explains that distinction. Paid checkout and purchases remain disabled.

The native ad work passed a 46-test focused run and a 15-test final regression run, with clean static analysis. The public web packager passed 12 tests and validated the complete generated artifact. The deployed site reports `0.12.0+35`; its public ad-status metadata and privacy/support file hashes match the package. Browser review confirmed game launch, tile input, hints and settings. The signed owner-review iOS build installed successfully in place on the connected iPhone; device launch and real-unit test-device verification remain pending. The 905-test result in the 0.11.4 notes is an earlier baseline, not a claim about this release.
