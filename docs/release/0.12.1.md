# Glowpath 0.12.1

Version `0.12.1+36` refines the countdown, timeout flight and collection navigation.

## Flight continuity

The horizontal countdown uses the full instrument width, with its readout above the end of the flight path. The vertical fold countdown reduces unused space between the ascent rail and the timer.

At timeout, the game captures the visible rocket's painted position, rotation, scale and exhaust. The countdown hands that craft to the loss scene, which starts in the same place and curves into the fracture and drift sequence. Retry restores the countdown. Reduced-motion preferences still use the quieter presentation.

## Voyage and collection

The full-screen universe now reserves the actual collection footer height, including safe areas and banner space. Planet route markers and the arriving rocket stay clear of the collection row without hiding the markers. The camera stays fixed between routes on the same planet.

Trails and Achievements use horizontal page carousels: outgoing and incoming artwork move with the finger, and chevrons animate the same pages. Large-text layouts support the same interaction. Cargo retains its separate 3D orbit gesture.

## Verification

Focused checks cover phones, tablets, enlarged text, cover-screen ascent, partially open book and flip layouts, repeated timeout/retry, gallery dragging and arrow reversal. The handoff tests compare the last painted countdown pose with the first loss frame and verify that only one rocket is visible. Static analysis passes. These are simulated layout and rendering checks; they do not replace physical fold-device playtesting.

Owner-review builds add consent/ad diagnostics that report status and error codes without logging consent strings or SDK response payloads. Public builds remain silent. Web ad approval and integration are tracked separately from these visual changes.

## Web advertising status

On 25 November, AdSense enrollment reached the dashboard, the `glowpath-38p.pages.dev` site was added, and Google verified its already-published publisher meta tag. The site review request was submitted successfully; the dashboard confirms that setup steps are complete. Approval and browser ad integration remain pending, so the public game still makes no advertising requests. No custom domain was added.
